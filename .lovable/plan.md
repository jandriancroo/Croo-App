## 2. The multi-store blocker — real, and here's exactly what it takes

Confirmed real, and it is not a permissions problem I can route around.

- I have full database access and can call PFG directly. That isn't the issue.
- South Meadows is the only store with a live access token saved. The other six saved a refresh token an hour ago and their access tokens are already expired.
- I tried the clean route first: logging in fresh with each store's saved username and password. **All seven failed**, South Meadows included, with the same PFG error. So that route is closed from here regardless of mode — PFG appears to block it by location or require the browser flow.
- That leaves each store's refresh token, and PFG replaces a refresh token the moment it's used. If I use one and the new one isn't saved back, that store's nightly sync stops working. Saving it is a write, which plan mode forbids — so the constraint is genuine, not a technicality.

**What build mode would actually involve.** Close to your description, with one addition:

1. Trigger the app's existing PFG refresh for one store — the routine that already runs nightly and already saves the replacement token. Nothing new gets written; it's the same write the app does on its own schedule.
2. Then the three read-only calls with that fresh token: list enumeration, the `SortByType: 0` category check, and the bulk pricing check.
3. Repeat per store, one at a time, checking each store's tokens survived before moving on. Six stores, roughly ten minutes.

The addition: the tokens are short-lived, about an hour, so this has to be done in one sitting rather than spread across the night. And if any store's refresh token turns out to be stale, that store simply can't be tested until someone signs in to PFG for it — I'd flag it rather than guess.

Nothing gets created or ordered on the PFG side by any of this. The only write is the token the app already rewrites nightly.

Say the word and I'll run that in build mode; otherwise the four fixes still ship South-Meadows-first, as laid out in the sequence I gave you.
