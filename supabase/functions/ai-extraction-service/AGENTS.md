- Thermometer photos are read only by ai-extraction-service extract-temperature: two parallel GPT-6 Luna reads (prompt has first-class digital/7-segment rules incl. rotated/upside-down displays, plus the store dial colour rule, unchanged). Agreeing reads (<5°F apart) save as confirmed. One failed or disagreeing reads get exactly ONE third tie-break read; if it agrees within 5°F with one of them that pair is averaged and saved confirmed, otherwise NO number comes back (reason reads_disagree / one_read_failed / read_failed) and the client opens Fix the number with the photo kept. A wrong number is never saved from a disagreement. Reads the model flags CLEAR: no come back as reason 'unclear' + coaching (too_far | too_dark | blurry | glare, fixed set); the client rejects that photo (nothing saved) and shows a retake tip. Client sends itemName. Disagreements, tie-breaks (tiebreak_confirmed) and unclear photos are logged with all reads in temperature_read_issues. Decision lives in temperatureDecision.ts, reply parsing in parseTempReply.ts. Retakes/rescans never overwrite a saved value with null. Why: upside-down probe screens were misread (Sparks 38.6 read as 49.8) and the first read was kept on disagreement.
- Ship 2 (Nov 17 2026): before the reads, the photo is turned 0/90/180/270 in code (orient.ts, imagescript) and one pick call returns UPRIGHT: 1-4; the reads run on that upright copy (any failure → read the photo as taken). Reads report TENTHS: sure|unsure|none; if either read of the agreeing pair is unsure of the tenths digit, or the pair agrees on the whole degree but not the tenths, the saved value is the whole degree cut toward zero (41.7 → 41, never rounded up). The client sends equipmentType (checklist_items.equipment_type); bands live in ../_shared/tempBands.ts (shared with the app). Outside the tag's possible range → no number, reason 'implausible' (crew retakes or types, photo kept). Inside possible but out of compliance → saved, isValid false. Hot tags (hot_holding / reheating) return verdict 'borderline' just under the line; the client asks for ONE retake. Untagged items keep the old -60..250 check and 41/135 rule. Why: Sparks' upside-down LCD (~36°F) was read as ~75 by both reads.
